# 下拉候选删除与滚动条检查

2026-11-02。

## 实现

用户要求优化滚动条、补齐候选行删除。滚动区使用8px占位/透明轨道，thumb通过2px透明边框形成4px可见滑块、999px圆角与悬停加深，去掉原生箭头。覆盖规则列表、编辑正文、候选列表与操作菜单；保留原生滚动/键盘能力。

候选原有56px操作列容纳“使用/勾号”和24px删除按钮，垃圾桶行悬停/键盘聚焦才出现。删除在菜单底部确认，当前值提示使用首个剩余值；目标行在确认区展开后滚入可见范围。成功保持菜单与搜索，失败保留确认与重试焦点。取消不修改配置；最后一个候选UI禁用且后台拒绝。

REMOVE_RULE_VALUE通过既有串行控制器合并最新候选，按值移除并同步删除对应别名，支持空值；删除非当前值不切换，删除当前值回退第一项。旧环境/不存在候选/最后一项请求被拒绝；不覆盖其他字段，DNR/storage失败回滚，暂停/停用不变。新增/编辑/删除互斥，提交复用busy/inert/aria-busy。无依赖、权限或schema变化；沿用既有反馈和减少动态效果。
