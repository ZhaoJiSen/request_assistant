# HeroUI样式借鉴检查

## 范围

仅修改popup共享CSS和设计说明。优先借鉴HeroUI官方按钮、Select、Dropdown、Tabs及Switch的视觉语言，保留现有Vue组件、语义、键盘交互及后台链路。无新增npm依赖、字体、图片、远程脚本或权限。

统一字段12px、浮层20px、胶囊按钮圆角及中性表面/阴影变量；浅灰搜索、筛选、候选值和表单，胶囊复合按钮、计数与环境选择，圆角矩形开关。导航保留下划线，不恢复常驻底栏和网站卡片。

## 验证

- `npm run typecheck`通过。
- 17项候选值真实Chrome回归通过：实际网络切值、刷新读回、键盘选择、别名/搜索/快捷添加、失败保留、并发保护、掩码、30项上限及短视口固定操作区。
- 原生Chrome工具栏popup连开三次与添加/导入编辑页尺寸通过；固有宽480px，实际视口495×498，内容和提交区域可见。
- 查看480×600列表、候选菜单、操作菜单和编辑页，保留2倍像素局部用于可读性核对；本轮未声称验证浏览器200%缩放重排。
- 参考为HeroUI官方当前组件页面及官方仓库v3样式，链接见`docs/DESIGN.md`。参考截图、实现截图及独立评审记录在`evidence/heroui-style`。
- 独立存量润色评审一轮、不打分，无必修项；编辑页占位文字略偏灰绿作为后续可选建议记录，本轮不追加调整。
