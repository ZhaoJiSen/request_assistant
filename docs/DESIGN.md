# 设计说明

用户已选择方向 1「轻量工具面板」，并确认两种 Cookie 能力均需实现。

## 北极星

打开就知道当前网站用了哪些配置，改完能明确知道是否生效。

面向频繁联调接口的开发者。主任务是修改配置、切换启用状态、确认适用域名；网站 Cookie 与请求头 Cookie 必须分开表达。

## 视觉决定

- 固定目标视口 480×600，符合 Chrome popup 最大高度；内容区独立滚动，保存按钮和状态栏固定在底部。
- 网站主机是最重要的上下文。品牌为 16px；当前网站为 15px，参数名为 14px 等宽字，辅助信息不小于 13px。
- 白色画布 `#ffffff`、石墨正文 `#20282d`，青绿色 `#087f73` 统一用于启用、选中和主操作。该颜色在密集调试工具中表达可操作状态，避免把一屏规则变成彩色标签。
- 开放式行列表，不层叠卡片。当前网站使用浅底分组，其余结构用留白和细线。
- 敏感 Header 与全部 Cookie 默认遮罩。图标来自同一套 Lucide，通用按钮有可访问名称。
- 首轮参考实际查看过 ModHeader 与 Requestly 官方页面；获取到的是官网展示，未将其当成已验证的插件交互。此项目采用紧凑、站点优先的弹窗结构，与两者营销首屏的构图和视觉主角不同。
- 参数本身是内容主角，未使用图片或气氛插画。

## 关键状态

初始化、空列表、筛选无结果、启用/停用、总暂停、编辑、保存中、保存失败、同步异常、非网站页面、网站 Cookie 列表、删除确认。

Header / 请求 Cookie 保存仅在规则与配置均成功时显示结果；失败保留编辑内容并将错误滚入视口。Cookie 写入后重新读取验证。网站 Cookie 的实际发送仍由浏览器策略决定。

## 动效

短促的「咔嗒—拨动开关」手感：开关 200ms，标签选中底板 230ms，按钮按下立刻缩到 0.98；编辑面板从右侧 18px 进入、12px 退出；首次列表出场位移 4px，提示条从底部 8px 进入。减少动态效果时直接展示最终状态。

## 减法与评审修正

保留三种能力的业务区分说明，删除空状态中重复的中央「添加规则」入口和泛化解释。

独立静态评审首轮 8/10：压缩品牌行、加强编辑可发现性、确认滚动末尾留白、缩短空状态文案。已缩小品牌、放大当前网站、加入铅笔按钮、在列表底部留 24px 空间，并固定底栏。

不提供请求监控、响应头改写、账号同步、远程配置或 Cookie 自动去重。这些不是本轮用户要求的能力。


## 2026-10-21 样式精修

沿用方向 1。北极星补充：一眼分清网站上下文、配置类型与主操作，清晰胜过装饰。

- 用石墨色正文与中性灰辅助文字修正整屏偏灰绿的问题；青绿色仅强调启用、选中与主按钮。品牌 17px，区块标题与空状态 16px，辅助文字 13px。
- 当前网站整合成一行上下文，去掉右侧重复的无网站提示；非网站页面明确提示切换到网站页面。
- 三个功能用统一分段导航，白色选中底板滑动；搜索与范围筛选统一高度、边框和圆角。
- 空状态按 Header / 请求 Cookie 分别说明用途，不再泛指两种能力；不增加重复的添加按钮。
- 编辑页同步更新标签、页头和底部操作区，保留独立滚动及原生弹窗 480px 固有宽度。业务与权限无变化，未添加图片；参数与状态才是工具的内容。
- 沿用按压、开关、导航底板、编辑面板与入场动效，减少动态效果仍有效。

## 环境配置组与自定义选择器

继续使用轻量白底、石墨正文、青绿色动作的方向，不额外增加导航页或装饰区。环境入口放在顶栏，规则列表保持原有空间。顶栏环境下拉右侧提供管理按钮；品牌字号 16px，环境文字与辅助说明 13px。

- 环境相互独立保存 Header 与请求 Cookie 规则，同一时刻只启用当前环境。总暂停跨环境保持。
- 现有规则无损迁入“默认环境”，保留规则 ID、启用状态与值，并保留迁移前本机备份。
- 管理页支持新建空白组、复制独立规则、重命名和删除。创建/复制后明确切换新环境；删除当前组先确认，再切换剩余首组；至少保留一个环境。最多 30 个环境、全部规则共 500 条。
- 网站 Cookie 始终按当前网站读取，不随环境切换写入、替换或删除。未做其他建议功能。
- 筛选、生效范围、Cookie 注入方式、SameSite 与环境选择全部复用 UiSelect。统一箭头右侧留白、白色菜单、选中勾号、不可用状态；支持方向键、Home/End、Enter/Space、Escape、Tab、文字匹配及外部点击关闭。菜单按可用空间向上/下展开，长菜单独立滚动。
- 沿用按钮按压、开关、导航底板与编辑转场；菜单 120–160ms 淡入/3px 位移和箭头旋转，减少动态效果时直接展示终态。
- 新增文案仅解释组隔离、创建后切换与删除后回退；沿用紧凑布局，没有新增重复主操作。

## 批量粘贴与导入导出

沿用已选定的轻量工具方向。目标：把将发生的修改看明白再写入；不新增主导航，不把导入导出做成比“添加规则”更强的入口。

- 三个标签页标题行增加次要的导入、导出入口。导入沿用全高编辑侧页，输入区独立滚动，底部主按钮固定。480×600 为目标尺寸，另检查 480×400 与真实工具栏弹窗。
- Header 支持多行“名称: 值”、JSON 对象及规则数组/本插件文件；保留值内冒号与合法空值。请求 Cookie 支持整段 Cookie 请求头和规则文件。原始文本使用所选范围，文件内已有范围保留。
- 规则只导入当前环境；导出当前环境、当前标签页的所有规则，包括停用项。导入生成新 ID，同范围覆盖保留已有 ID；默认跳过同名同范围项目。各环境仍相互隔离，总暂停仍保留。
- 网站 Cookie 支持 name=value 字符串、Chrome Cookie JSON 数组及本插件文件。JSON 保留 Domain、Path、hostOnly、Secure、HttpOnly、SameSite、会话/过期时间及当前分区；存储区使用当前网站所在浏览器容器。字符串覆盖只更新值、保留已有属性；只能导入当前网站及合法父域，分区 Cookie 限当前分区。
- 导入分“输入—解析预览—确认写入”，预览列出新增/覆盖/跳过、目标范围和可查看的值；敏感 Header 与全部 Cookie 默认遮罩，空值单独标注。网站 Cookie 预览额外列出关键属性。每批 1–500 条、最大 1 MB，重复或无效项目先报错。
- Header/请求 Cookie 沿用控制器整批校验、DNR 更新与存储失败恢复。Cookie API 无跨项事务；先完整校验，再逐项写入/读回，结果明确给出已写入、跳过与失败，失败后只保留失败项。预览后环境/规则或 Cookie 改变时拒绝旧批次。
- 导出内容默认隐藏，支持主动显示、复制 JSON 与下载 JSON；当前网站/环境始终在页头内容区明确展示。导出文件包含完整值，界面只保留一次必要的保管提醒。
- 沿用按钮按压、编辑页进入/退出与首次出场动效，解析预览有 200ms 轻入场，复制后按钮变为勾选反馈；减少动态效果直接到位。不增加动效库或图片素材，数据就是主角。
- 本轮独立存量润色评审一轮、不打分，补齐预览值和空值；删去预览底栏重复容量限制及导出中央重复说明，失败原因分出名称与原因层次。修正后由主 Agent 自检，没有另称第二轮独立评审。

## Header 多候选值与列表快速切换

目标是让 pversion-id 等频繁切换的 Header 不必反复进入编辑页。沿用白底、石墨正文和青绿色动作的已确认方向，主角仍是规则及当前值；只有至少两个候选值时，在原值的位置显示复用的 UiSelect。编辑按钮继续负责维护候选集合。没有新增导航、菜单系统或额外工具栏。

编辑页以单个值起步，「添加候选值」展开下一项并聚焦；有多个值时用单选按钮标识当前使用项，选中项只增加浅色边框和背景。候选行可删除，表单独立滚动，保存操作固定在底部。选择器沿用键盘操作、视口边界定位与菜单过渡；候选选中边框/底色为 160ms，减少动态效果时禁用新增过渡。

数据沿用 version 2：Rule.value 为当前生效值，Header 可选 values:string[] 保存候选集合；旧数据未包含此字段时直接按单值处理。限制 1–30 个候选值，允许空字符串，验证所有候选值并禁止重复。切换操作由后台串行修改最新规则的 value，校验当前环境与候选集合，再通过既有 DNR/storage 提交与回滚流程保存。不会覆盖并发修改的其他字段，也不会打开暂停的注入开关。

JSON 导入/导出与环境复制保留候选集合和当前选择；搜索可匹配候选值；敏感 Header 的列表下拉默认只显示候选序号和掩码，沿用显示值按钮揭示内容。请求 Cookie、网站 Cookie 未加入候选集合。本轮是局部功能增补，由主 Agent 检查截图和真实流程，未另行独立评审；未增加多余装饰和重复说明。
