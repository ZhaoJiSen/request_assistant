# 复合搜索/筛选控件焦点修复

2026-11-02。

用户指出“全部规则”展开时右侧高亮有方形割裂。本轮仅修改共享CSS中该复合控件相关选择器，不改布局、菜单定位或业务。

## 修复

右侧UiSelect的独立展开阴影及较深背景与单侧圆角叠加，形成局部方形边缘。现改为父级统一承载搜索/筛选的焦点边界：完整10px圆角、连续细青绿边与浅焦点环；子输入和筛选按钮不再重复描边。菜单展开时用`:has()`保持整组高亮，搜索或键盘聚焦用`:focus-within`保持可见反馈。筛选仅保留轻悬停背景、分隔线及箭头旋转。

搜索字段只在该复合控件使用；其他UiSelect的展开、键盘焦点、浮层样式未变。边界150ms过渡由既有全局减少动态效果规则覆盖。
