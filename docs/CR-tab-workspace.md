# Tab与对应内容归属修正

2026-11-02。

用户明确指出Tab与其对应的内容应是一体，上一轮导航位于白色顶部、内容处于另一块浅灰底色的分区不成立。

## 修改

- 新增唯一的`tab-workspace`父容器，同时包裹Tab导航、错误提示与当前tabpanel；全局网站/环境/总开关仍位于外部。
- 导航与内容使用连续浅灰表面和统一圆角外框，删除原有中间分隔线及白灰背景切换。搜索、筛选、添加与规则列表均属于当前Tab。
- 保留既有规则卡片、键盘切换、ARIA关联、菜单Teleport与减少动态效果。容器flex/min-height为0、内部列表独立滚动，未修改数据或权限。
