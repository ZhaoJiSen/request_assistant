## 实现检查

- 网站上下文并入字标下方，长域名省略并保留完整URL悬停；匹配信息保留在悬停与可访问文本，规则应用异常继续由alert明示。

- 搜索与范围筛选复合为一个控件，添加及附属菜单并排对齐。保留搜索清空、范围选择和已有菜单键盘/外部关闭逻辑；没有新增数据写入入口。
- 网站Cookie工具栏没有范围选择器，说明与浏览器Cookie状态继续展示；原生480px固有宽度与内容区滚动机制未变。
- 清理被替代的区块标题、计数、筛选行样式；按钮、菜单、开关和减少动态效果处理沿用已有实现。
