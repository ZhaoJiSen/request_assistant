# Header 搜索、添加与别名自审

日期：2026-11-02。范围：相对 0ed343d 的候选值搜索、快捷添加、别名及相关文档/测试。实现者代码自审；独立 UX 走查单独记录，不等同独立代码审核。

## 结论与检查

未发现阻塞功能交付的代码问题。

- 兼容：valueAliases 可选且与 values（单值则为 [value]）等长，不改变既有 value 的网络含义。别名为最多 48 字符的单行文本；新旧配置、空值、导入导出及环境复制均有针对性验证。
- 并发：新增走 ADD_RULE_VALUE，在控制器队列中读取最新规则再追加；只改候选集合、别名和当前值。校验当前环境、规则、重复与 30 项限制，保留最新规则的范围、名称与启用状态；失败前验证，不原地留下无效候选。
- 恢复：DNR/storage 失败使用原控制器回滚；单测覆盖两种失败后的配置与实际安装规则。界面错误保留值、别名及当前位置。
- UI：Header 使用可搜索的复合选择器，其他选择器仍复用原行为。搜索/底部动作固定，选项独立滚动并限制在视口内；键盘可选择及进入添加动作，Escape/取消恢复焦点。新增保存后等 busy 解除再恢复触发器焦点。
- 敏感值：菜单、选中区和悬停文字均使用遮罩后的展示内容；未揭示时按别名及可见文字搜索。Vue 文本插值不将别名当 HTML。
- 草稿：值与别名同步增删，打开规则时清理上一次可选字段。单值也有添加入口。别名不参与 DNR 编译。
