# 复合操作按钮禁用一致性

2026-11-02。

用户反馈：写入Cookie主按钮和菜单项均禁用时，附属箭头仍显示可用，造成状态矛盾。

## 修改

`RuleActions.vue`根据导入、导出、重新读取/应用操作是否全部不可用计算菜单禁用状态，并合并已有全局disabled。箭头使用原生disabled与现有0.5透明度，主按钮同时不可用时外观一致。展开入口增加状态守卫，菜单展开后操作变为全部不可用时自动关闭。仍有可用菜单项时正常展开，维持单项禁用。

未改变布局、样式变量、权限或数据行为。无新增动效；现有菜单退出与减少动态效果处理沿用。
