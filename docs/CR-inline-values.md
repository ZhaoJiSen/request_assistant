# 候选值与别名行内编辑检查

2026-11-02。

## 用户目标与实现

用户希望直接点击下拉选项中的值或别名编辑，避免进入Edit页。沿用现有两列、搜索和固定添加入口：单元格原位输入，勾号/Enter保存，叉号/Esc取消；菜单保持打开，行右侧“使用”或勾选状态负责切换。

- `EDIT_RULE_VALUE`后台串行合并最新规则，仅修改目标候选字段。修改当前候选时同步更新Rule.value；未选中候选和别名不改变选择。单值与空值受支持。
- 校验当前环境、候选存在性和旧别名，拒绝旧请求；全量validateRule先校验再赋值，避免失败时部分修改。候选去重、长度、单行限制及DNR/storage失败回滚复用既有控制器。暂停、单条停用与并发修改的其他字段保留。
- UiSelect增加可选的行内保存回调；仅Header候选启用。该模式改用非模态dialog、list与明确命名的按钮，避免在listbox option中嵌套输入控件。普通筛选/环境/表单UiSelect保留原有语义与交互。
- 键盘搜索方向键/Enter继续选择，Tab可进入编辑按钮；输入法组合期间Enter/Esc不提交或取消。敏感值未显示时实际值编辑按钮禁用，别名仍可编辑。
- 保存期间主界面inert，当前Teleport菜单继续可见并aria-busy，内部保存/取消/切换/添加暂时禁用。成功保持菜单与搜索，失败保留输入、焦点和行内错误。未保存草稿在显式关闭或开始其他单元格时取消，不自动写入。
- 保留完整编辑与快捷添加。数据schema仍version 2，环境复制及JSON导入导出复用现有values/valueAliases。无新依赖、权限、资源或截图专用产品入口。
