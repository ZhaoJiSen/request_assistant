# 工具栏与底栏简化检查

## 改动与边界

- 添加主按钮与更多操作组成分裂按钮；导入、导出、重新应用/重新读取使用原有处理函数。
- 删除常驻底部计数及操作栏，无网站时隐藏站点上下文，标签页改为下划线；保留异常 alert、标题计数、暂停文案和站点匹配信息。
- RuleActions 为语义化按钮与 menu/menuitem，不借用 select 语义。菜单 Teleport 避免滚动容器裁切，按视口定位；支持方向键、Home/End、Escape、Tab、外部点击与选择器互斥。禁用状态和事件监听清理完整，定位仅在坐标变化时更新响应状态。
- 未修改后台、权限、配置结构或导入导出格式。开发预览检查临时使用内存中的展示状态，未增加产品测试入口或写入用户扩展配置。

## 验证

- 类型检查通过；14项真实 Chrome 导入导出回归通过，包含 Header 与请求 Cookie、网站 Cookie、实际请求、下载和刷新读回、失败保留、部分写入与重试。
- Chrome 原生工具栏 popup 连开三次通过，固有宽480px，实际可用视口495×498；添加及导入编辑页的固定提交区均可见。
- 既有16项浏览器回归通过，覆盖总开关、Header与Cookie实际网络行为、保存读回、失败保留、列表末项、Cookie编辑删除与过期上下文保护。
- 主 Agent 实际检查菜单方向键、Home/End、Escape恢复焦点、Tab和外部点击关闭；480×400菜单不溢出。减少动态效果时菜单和下划线过渡为0s。
- 查看480×600空态/规则/菜单、网站Cookie无网站状态和2倍像素局部；独立存量润色评审一轮、不打分，无必修项。截图顶栏边缘的证据疑问另用完整局部图核实，品牌文字位于y=21.5至41.5px内，未裁切。
- 首次使用开发热更新产物时，原生打开和页面重载出现超时；改用不依赖热更新服务的独立开发产物后通过。后续导入导出旧测试仍等待已移除的刷新按钮，已改为读取tabpanel的aria-busy，再次通过。

证据：`evidence/compact-controls`、`evidence/import-export`、`evidence/native-popup`。未生成新的生产ZIP，项目根目录已有ZIP仍是上轮版本。
