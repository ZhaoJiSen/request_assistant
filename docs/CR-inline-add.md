# 下拉菜单原位添加候选值检查

2026-11-02。

## 实现与交互判断

用户指出添加值不应跳转。该菜单已支持切换和行内编辑，新建同组候选应在原处完成。底部入口展开值与可选别名两列输入；主动作“添加并使用”明确保存后立即选中的既有语义，取消/Esc保留原选择与搜索。保存失败显示局部错误并保留草稿，成功清空搜索以展示新候选、保持菜单并聚焦搜索。

- 复用既有ADD_RULE_VALUE后台串行合并/验证/回滚，不改数据schema、权限或依赖。个别规则停用和全局暂停不因新增而自动开启。
- UiSelect仅增加可选异步新增回调；新增与编辑互斥，提交期间复用busy、inert与aria-busy。通用选择器与两种Cookie能力不变。
- 移除独立添加候选值页的死分支、状态及样式；完整规则编辑里的候选管理保留。
- 按钮、菜单、Toast沿用现有反馈；新增表单160ms淡入及3px原位出现，减少动态效果时不播放。
- 修正保存后聚焦时搜索尚为disabled的问题，同时让已有行内编辑也先恢复可用再聚焦；隐藏铅笔样式提高优先级，避免button:disabled使其重新显露。
